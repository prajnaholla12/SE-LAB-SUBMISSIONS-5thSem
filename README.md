# Jira Hands-on – Agile Backlog Creation & Sprint Simulation

## Overview
Submitted on 8th september 2026 on Teams. Recreated Repository later due to technical issues 
This lab demonstrates the use of Jira for Agile project management using the **Municipal Solid Waste Route Optimizer (MSWRO)** project.

## Objectives
- Create epics and user stories.
- Assign story points and priorities.
- Organize the backlog and plan a sprint.
- Track task progress using the Active Sprint board.
- Analyze sprint progress using the Burndown Chart.

## Tools Used
- Jira Software
- Agile Scrum methodology

## Key Activities
- Created epics for Smart Bin Monitoring, Waste Collection Route Management, and Citizen Complaint Management.
- Added user stories and assigned story points and priorities.
- Planned and managed a sprint using the Scrum board.
- Reviewed sprint progress through Jira reports.

## Learning Outcomes
Gained practical experience with Agile backlog management, sprint planning, task tracking, and progress visualization using Jira.
