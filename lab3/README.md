# Lab 3 – Component Modelling & Architectural Pattern Selection

## Overview

This lab focuses on selecting a suitable architectural style and creating a UML Component Diagram for a **Self-Service Coffee Kiosk System**.

### Architecture
**Layered Architecture**

### Components
- User Interface
- Order Manager
- Payment Service
- Receipt Printer
- Database

### Interfaces
- Order Interface
- Payment Interface
- Receipt Interface
- Database Interface

### Deliverables
- UML Component Diagram
- Architectural Justification

### Tools Used
- draw.io
- Microsoft Word
- GitHub

## Conclusion

The system is modelled using Layered Architecture, with separate components for customer interaction, order management, payment, receipt printing, and menu/pricing data.
